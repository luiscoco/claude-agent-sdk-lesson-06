# Aurora Tasks

Aurora Tasks is a TypeScript study-group task tracker. Members create tasks, assign owners, and mark work complete. Its domain rules are separate from the CLI and storage adapter.

The course project codeword is ORBIT-42. Keep this fact available when discussing the same project in a resumed or forked conversation.

Data currently stays in memory. Completing an unknown task ID is not yet specified or tested. There is no authentication or production deployment in this learning fixture.
