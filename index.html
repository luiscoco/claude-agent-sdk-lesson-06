DISTINCT SURFACES, CONNECTED LIFECYCLES

          
Capabilities, specialists, and saved context.

          

            The sample follows the installed 0.3.310 signatures. Its SessionStore adapter is
            explicitly alpha and deliberately scoped to this workshop.
          

        

        

        

          

            
A retained query connects the parts

            
const q = query({ prompt: input, options });
await q.initializationResult();
await q.setMcpServers({ project: server });
await q.mcpServerStatus();
await q.supportedAgents();
// Queue the task, consume typed messages,
// then close the query in finally.

            

              The workflow consumer runs alongside runtime control requests. Discovery is complete
              before user input is submitted.
            

          

          

            
Continue a branch deliberately

            
const branch = await forkSession(sourceId, {
  dir, sessionStore, title: 'Alternative review'
});
const q = query({
  prompt: input,
  options: { resume: branch.sessionId,
    persistSession: true, sessionStore }
});

            

              Forking preserves the original conversation. Session history does not restore
              filesystem state.
